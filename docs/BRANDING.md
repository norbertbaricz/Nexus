# Nexus identity and asset notes

## Changes in this version

The N mark now uses one continuous stroke with a uniform weight. The previous overlapping path and extra ornament are removed, and the favicon uses the same geometry.

The application uses two labeled main sections, Messages and Servers, a contextual channel sidebar, server image cards and real conversation lists. It avoids the previous stack of community icon buttons. Neutral charcoal surfaces and restrained coral accents define the product rather than another platform's visual identity.

The original connection artwork is retained as a local geometric SVG. Notification and call cues are original synthesized Web Audio patterns in public/sounds.js; no sampled platform sounds are used. Interface glyphs include locally edited Feather SVG adaptations, distributed with their MIT notice under licenses/. No external icon CDN, web-font CDN, platform logo, borrowed notification sound or third-party screenshot is embedded in the app.
